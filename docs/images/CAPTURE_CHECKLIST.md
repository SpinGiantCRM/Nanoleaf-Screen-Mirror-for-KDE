# Screenshot capture checklist

Capture these from a live KDE Plasma 6 session for the README visual section.

| Asset | What to capture |
| ----- | --------------- |
| `tray-menu.png` | Tray icon open showing Start, Set up strip…, Help & Diagnostics |
| `setup-wizard.png` | Setup wizard step 1 with checklist and corner calibration |
| `settings-everyday.png` | Settings → Everyday page |
| `calibration.png` | Strip setup or wizard during test pattern |
| `help-diagnostics.png` | Help & Diagnostics overview tab |
| `edge-mirror.gif` (optional) | Short clip of screen edge colour → strip response |

Save files under `docs/images/` and reference them from README above the Install section.

Recommended size: 1200–1600 px wide PNG; keep personal wallpaper/content neutral if possible.
