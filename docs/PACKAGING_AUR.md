# Historical AUR packaging retired

The old Python AUR recipe, wheel and PyPI release workflow are retired. There is
currently no replacement native AUR recipe maintained in this tree. Use the
[immutable native bundle](NATIVE_INSTALL.md) and its rollback mechanism. This
source cleanup does not modify an external AUR repository or remove published
PyPI releases. Historical packaging is retained in Git history before
`85f59888d373667f48651f8cbb2333b8605bfbc5`.
